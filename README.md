# GPOprogetto

# Titolo
Parkly
# Descrizione / Tagline
Parkly – Trova il parcheggio migliore al prezzo migliore.
App web che permette di trovare e confrontare i parcheggi di una zona, sia gratuiti che a pagamento, in base a prezzi e caratteristiche.
# Problema che vuole risolvere
Difficoltà nel trovare rapidamente parcheggi e confrontare i relativi prezzi.
# Mission
Semplificare la ricerca dei parcheggi, aiutando gli automobilisti a risparmiare tempo e denaro.
# Vision
Diventare un punto di riferimento per la ricerca e il confronto dei parcheggi, rendendo la mobilità urbana più semplice e accessibile.
# Target
Automobilisti, pendolari, studenti, lavoratori e turisti.
# Competitors
Parkopedia, Google Maps, EasyPark, Parclick.
# Tecnologie
C#, ASP.NET Core, Razor Pages, HTML, CSS, JavaScript, SQL Server, GitHub.
